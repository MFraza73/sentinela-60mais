# Glossário: o que evitar e o que usar

O verificador (`scripts/checar_alerta.py`) procura os termos da coluna "Evitar". Se um deles for
indispensável, explique-o na mesma frase, entre parênteses, e aceite o AVISO.

## Termos técnicos e estrangeiros

| Evitar | Usar |
| --- | --- |
| phishing | mensagem falsa |
| spoofing, número mascarado | número falsificado (parece do banco, mas não é) |
| engenharia social | conversa feita para enganar você |
| deepfake | vídeo ou voz falsos feitos no computador |
| clonagem de voz por IA, voz sintética | voz copiada por computador |
| link malicioso | link falso |
| malware | programa espião |
| app | aplicativo |
| token | código de segurança |
| autenticação de dois fatores | confirmação em duas etapas |
| QR code | código QR (o quadradinho que a câmera lê) |
| credenciais | senha e dados de acesso |
| dados sensíveis | senha, número do cartão e códigos |
| transação | pagamento ou transferência |
| beneficiário | quem vai receber o dinheiro |
| estelionato, fraude | golpe |
| central de atendimento | telefone do banco |
| empréstimo consignado | empréstimo descontado direto da aposentadoria |

## Verbos de repartição pública

| Evitar | Usar |
| --- | --- |
| efetuar, realizar | fazer |
| solicitar | pedir |
| contatar | ligar para, falar com |
| informar | avisar, dizer |
| acessar | entrar, abrir |
| ressaltamos que, cumpre informar | (apagar) |

## Termos pejorativos ou infantilizantes

Nunca use: vovô, vovó, velhinho, velhinha, idosinho, ingênuo, desatento, "cair como um patinho".

## Siglas

Escreva o nome completo antes da sigla na primeira vez.

| Sigla | Primeira menção |
| --- | --- |
| INSS | Instituto Nacional do Seguro Social (INSS) |
| SMS | mensagem de texto (SMS) |
| FGTS | Fundo de Garantia do Tempo de Serviço (FGTS) |
| SAC | Serviço de Atendimento ao Consumidor (SAC) |
| BO | boletim de ocorrência (BO) |

Exceções aceitas sem nome completo: **Pix** (nome próprio) e **CPF** (uso corrente).
