# Empréstimo falso em anúncio: não pague taxa para liberar

**Como chega:** Um anúncio de empréstimo fácil, com a marca de um banco ou do governo.
**O que pedem:** Uma taxa paga antes, para liberar o dinheiro.
**Sinal de golpe:** Nenhum banco cobra taxa antes de liberar empréstimo.
**O que fazer:** Não pague nenhuma taxa para receber um empréstimo.
**Para lembrar:** "Pediram taxa para liberar empréstimo? É golpe."

Fontes:
1. [Procon Exemplo](https://exemplo.org/procon-emprestimo)
